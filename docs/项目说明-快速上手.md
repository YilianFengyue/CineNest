# CineNest 项目说明 · 快速上手

> 目标：任何人 5 分钟读懂项目、跑起来、找到自己该改哪。

## 一、这是什么

**CineNest** = AI 驱动的个性化影视推荐 App。分布式两端：

```
┌─────────────────────────┐         局域网 HTTP / WebSocket        ┌──────────────────────────┐
│   手机端 cine_nest_app   │  ───────────────────────────────────▶ │   PC 端 cine_net_backend  │
│   Flutter (Android/鸿蒙) │  ◀─────────────────────────────────── │   FastAPI + LangChain     │
│   展示 / 播放 / 对话      │   /api/feed /api/sources /ws/chat ...  │   推荐 / 解析 / 海报 / 资讯 │
└─────────────────────────┘                                        └──────────────────────────┘
```

- **PC 端**是算力中心：TMDB 影视数据、LangChain 推荐 Agent、视频源解析、海报生成。
- **手机端**是交互界面：帖子流、详情、播放器、AI 对话。
- 用户在 App 设置页填 PC 的 `IP:Port` 建立连接（F7）。

| `pages/creative/` | 海报·对话·资讯 | **成员 C** |

> 基建从 PiliPlus 移植，已**剔除全部 B站强相关逻辑**（WBI 签名、AccountManager、
> cookie、弹幕、gRPC）。详见各文件头部注释。

## 三、5 分钟跑起来

### 后端
```bash
cd cine_net_backend
python -m venv .venv && .venv\Scripts\activate     # Windows
pip install -r requirements.txt
# 如需 Agent/TMDB，在 cine_net_backend/.env 手动填写 LLM_* / TMDB_READ_ACCESS_TOKEN
uvicorn main:app --reload --host 0.0.0.0 --port 8000
# 浏览器打开 http://127.0.0.1:8000/docs 看接口
```

### 手机端
```bash
cd cine_nest_app
flutter pub get
flutter run                                         # 选 Android 设备/模拟器
# App 起来后是底部导航空壳；设置页填 PC 的 IP:Port 测连接
```

> PC 与手机需在同一局域网。PC 的 IP 用 `ipconfig` 查（如 192.168.1.100）。

## 四、模块如何松耦合协作

连接关系是「路由跳转 + API URL」，**不是代码级依赖**：

- B 的帖子卡片 → 点击 → B 的详情页 → 「播放」→ 调 A 的 `/api/sources/*` → 跳 A 的播放器路由
- B 的帖子卡片海报 URL → 指向 C 的 `/api/poster/{id}`
- C 的对话推荐 → 点击 → 跳 B 的 `/movie-detail/:id`

详细接口契约见 [api_contract.md](api_contract.md)。

# 简版论坛真机测试流程

## 1. 启动后端

在 PyCharm 或终端进入：

```powershell
D:\AndoridProject\fastApiProject1
```

启动：

```powershell
.\.venv\Scripts\python.exe -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

浏览器访问 `http://127.0.0.1:8000/api/health`，确认后端正常。

## 2. 手机连接

1. 手机和电脑在同一个 Wi-Fi。
2. App 进入 `Settings`。
3. 输入电脑 IPv4 和端口 `8000`。
4. 点击 `Save and test`，确认已连接。

## 3. 进入论坛

1. 点击底部 `News`。
2. 点击右上角论坛图标。
3. 进入 `CineNest Forum` 页面。

## 4. 发帖

1. 点击右下角 `Post`。
2. 输入昵称、标题、内容。
3. 点击 `Publish`。
4. 返回论坛首页后，应看到刚发布的新帖子。
5. 下次再发帖时，昵称会自动带出。

## 5. 点赞与评论

1. 点击帖子进入详情页。
2. 点击爱心按钮，点赞数 +1。
3. 再点一次爱心，点赞取消。
4. 在评论区输入昵称和评论内容。
5. 点击 `Comment`，评论应出现在列表底部。

## 6. 搜索与排序

1. 回到论坛首页。
2. 在搜索框输入帖子标题或内容关键词。
3. 点击搜索按钮，应只显示匹配帖子。
4. 点击 `Latest` 看最新帖子。
5. 点击 `Hot` 按点赞/评论热度排序。

## 7. 常见问题

- 论坛打不开：先确认 Settings 里 PC 后端连接成功。
- 发帖失败：标题、内容、昵称都不能为空。
- 点赞状态没保存：退出 App 再进入，当前手机的点赞状态应保留；它依赖本机 `client_id`。
- 没有删除按钮：当前版本不做登录，所以不做删除，避免误删别人内容。
